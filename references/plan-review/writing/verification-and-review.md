# Writing verification and review

The plan must separate drafting fidelity, automated semantic review, revision, final validation, and
human acceptance. It names `.planning/AUTOMATED_REVIEW.md` for machine findings and
`.planning/HUMAN_REVIEW.md` for user dispositions. Review Surfaces identify the Markdown, DOCX,
Typst/TeX, and rendered artifacts the user will inspect and how freshness is proven.
